

# 六级词汇 · 全量精读系统

一个面向大学英语六级（CET-6）备考者的在线英语学习工具。网站以**完整词汇覆盖、主题文章精读、间隔复习和英文阅读拓展**为核心，帮助学习者在积累词汇的同时，逐步提高英语阅读理解能力。

**在线体验：** https://mengyangelin-a11y.github.io/english-six-level-AI/

## 一、项目简介

本网站以整理后的六级词汇表为基础，将 **3,777 个去重词条**编入 30 篇主题阅读文章，并配套词汇查询、每日测试、间隔复习和学习记录等功能。除了系统化的六级词汇学习，网站还设置了“每日英文期刊”模块，为学习者提供适合不同英语水平的英文阅读材料。

网站适合希望系统积累六级词汇、通过上下文理解单词，并保持每日英语阅读习惯的大学生使用。

## 二、主要功能

### 1. 六级全量词库

- 收录 **3,777 个去重词条**，覆盖本项目整理的完整词表。
- 提供英式音标、美式音标及中文释义。
- 支持按英文单词、短语或中文释义搜索。
- 可在全量词库中查询和学习单词，不局限于当天课程。

### 2. 30 天主题文章精读

- 将全部 3,777 个词汇分配到 30 篇主题文章中，每篇约 125—126 个目标词。
- 目标词在文章正文中以蓝色高亮显示。
- 鼠标悬浮或点击高亮词汇，即可查看音标和中文释义；手机端可直接点击查词。
- 每篇课程包含英文文章、中文导读、词汇释义、长难句分析和每日测试等学习内容。
- 支持切换课程日期，按顺序完成 30 天学习安排。

### 3. 间隔复习

网站提供“记得 / 忘记”复习反馈，并根据学习结果安排后续复习时间：

| 学习反馈 | 后续安排 |
| --- | --- |
| 记得 | 按 1、3、7、14、30 天逐步延长复习间隔 |
| 忘记 | 安排在次日重新复习 |

连续通过五个间隔阶段后，单词将标记为“已掌握”。系统会记录复习结果、下次复习日期和连续正确情况，帮助学习者优先处理到期或遗忘的词汇。

### 4. 词汇测试

- **每日测试：** 从当天文章的目标词中抽取题目，帮助检查当日学习效果。
- **全词库测试：** 从 3,777 个词条中随机抽题，可选择题量。
- 测试结果会计入学习记录，并辅助后续复习。

### 5. 每日英文期刊

“每日英文期刊”采用复古英文报纸风格，为六级学习者提供课外阅读入口。

- 优先推荐 CEFR B2（Upper-intermediate）难度的阅读材料，并提供少量 B1 热身内容和 C1 挑战内容。
- 文章来源包括英语学习机构、新闻英语栏目及科普类内容平台等。
- 支持按难度和主题筛选，也可以搜索标题、主题或出版来源。
- 可以将文章标记为已读或收藏，并查看已收藏文章。
- 点击文章入口可前往原出版方页面阅读。

**说明：** 本模块以精选文章及原文链接为主，内置推荐内容会在精选范围内轮换，并非实时自动抓取全网新闻。外部文章的版权归原出版方所有，网站提供阅读入口，不代替或复制原文内容。CEFR B2 可作为六级阅读练习的参考区间，但 CEFR 等级与大学英语六级难度并非严格一一对应。

### 6. 学习记录与进度备份

网站会统计已接触词汇、已掌握词汇、待复习词汇、文章完成情况、复习次数和测试记录等信息。

- 学习状态保存在当前浏览器中。
- 可使用“导出进度”或“导出完整进度”功能，将学习数据保存为 JSON 备份文件。
- 更换设备或浏览器后，可通过“恢复备份”导入之前保存的 JSON 文件。
- 建议定期导出备份，避免因清理浏览器数据而丢失学习记录。

**注意：** 当前学习进度保存在本地浏览器，不会自动在不同设备或浏览器之间同步。请妥善保存导出的备份文件。

## 三、建议学习流程

网站提供每日约 45 分钟的参考安排：

| 学习内容 | 建议用时 | 学习重点 |
| --- | ---: | --- |
| 旧词复习 | 10 分钟 | 优先完成到期和遗忘词汇 |
| 主题文章精读 | 15 分钟 | 先理解文章主旨，再结合上下文理解目标词 |
| 词汇学习 | 15 分钟 | 结合音标、释义和上下文积累词汇 |
| 每日测试 | 5 分钟 | 检查当天学习效果 |

每天约 125—126 个新词的安排强度较高，可以根据个人基础将学习任务分成两至三段完成。完成 30 天课程代表完成全部词汇的**首次覆盖**，并不意味着已经完全掌握；建议继续利用间隔复习功能巩固词汇。

## 四、使用方法

1. 打开在线网站：<https://mengyangelin-a11y.github.io/english-six-level-AI/>。
2. 在“学习总览”查看当前学习进度和今日任务。
3. 进入“今日文章”或“30天课程”，阅读当天主题文章。
4. 鼠标悬浮或点击文章中的蓝色高亮词汇，查看音标和中文释义。
5. 完成文章学习后进行每日测试，并在“间隔复习”中反馈单词掌握情况。
6. 可进入“全量词库”查询单词，或进入“每日英文期刊”进行拓展阅读。
7. 定期导出 JSON 学习进度备份；需要恢复时，使用“恢复备份”导入文件。

## 五、关于学习目标

本项目希望帮助学习者建立持续、可执行的英语学习习惯：通过主题文章接触词汇，通过查词和测试理解词义，再通过间隔复习巩固记忆，并借助英文期刊逐渐扩大阅读范围。

词汇数量和课程天数是学习安排，不是考试成绩保证。实际学习效果仍取决于个人投入、复习质量和长期坚持。
